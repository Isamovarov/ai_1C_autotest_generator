# Workflow v5

```text
1. Planner Agent
2. Vanessa Knowledge Agent — поиск похожих сценариев
3. EDT Agent
4. Query Agent
5. Vanessa Knowledge Agent — сопоставление действий с шагами
6. Feature Generator
7. Validator Agent
```

## Правила v5

- Query Agent только читает данные.
- Изменение данных допускается только шагами Vanessa.
- Свободный ввод можно заполнять сгенерированными тестовыми данными.
- Сгенерированные значения должны соответствовать формату реквизита.
- Если точная кнопка/команда не найдена, можно подобрать похожую по смыслу.
- Смысловая замена должна быть подтверждена через EDT-MCP.
- Отсутствующие некритичные реквизиты не блокируют генерацию feature.
- По отсутствующим некритичным реквизитам добавляются комментарии.

## Стоп-условия

Остановить процесс, если:

- нет существующего шага Vanessa;
- не найдены тестовые данные;
- не подтвержден критичный элемент и нет однозначной смысловой замены;
- нужен `execute_code`;
- нужно изменить данные через MCP;
- невозможно сгенерировать значение по формату;
- смысловая замена элемента неоднозначна.

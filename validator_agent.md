# Validator Agent

## Проверки

Проверить:

1. Все исполняемые шаги существуют в Vanessa Automation.
2. Каждый исполняемый шаг найден через Vanessa AI MCP.
3. Нет придуманных шагов.
4. Нет BSL.
5. Нет `execute_code`.
6. Нет действий, которых не было в тест-кейсе.
7. Нет проверок, которых не было в тест-кейсе.
8. Все критичные элементы подтверждены через EDT-MCP или однозначно сопоставлены.
9. Все тестовые данные из базы получены через `execute_query`.
10. Все сгенерированные значения для свободного ввода соответствуют формату.
11. Все смысловые замены элементов отражены комментариями.
12. Все отсутствующие некритичные реквизиты указаны комментариями.
13. Изменения данных выполняются только шагами Vanessa.

## Критические ошибки

`failed`, если:

- есть неподтвержденный шаг;
- есть BSL;
- есть `execute_code`;
- изменение данных выполняется не шагом Vanessa;
- отсутствует критичный элемент формы и нет однозначной замены;
- используются данные из базы не из `execute_query`;
- значение для свободного ввода не соответствует формату;
- смысловая замена элемента неоднозначна.

## Выходной формат

```json
{
  "validation_status": "passed | failed",
  "errors": [],
  "warnings": [],
  "recommendations": []
}
```

# Coding Guidelines v5

## Работа с данными

Тестовые данные из базы — только через ROCTUP/1c-mcp-toolkit:

- `get_metadata`;
- `execute_query`;
- `get_object_by_link`;
- `get_link_of_object`.

Запрещено:

- `execute_code`;
- BSL;
- изменение данных через MCP.

## Свободный ввод

Если поле поддерживает свободный ввод, можно генерировать значение.

Перед генерацией проверить через EDT-MCP:

- тип;
- формат;
- маску;
- длину;
- обязательность.

Если формат неизвестен — использовать безопасное строковое значение только для строкового поля без ограничений. В остальных случаях вернуть `ТРЕБУЕТ УТОЧНЕНИЯ`.

## Смысловая замена элементов

Если элемент не найден точным поиском, разрешен поиск похожего по смыслу.

Обязательно:

- подтверждение фактического элемента через EDT-MCP;
- комментарий в feature;
- существующий шаг Vanessa для работы с фактическим элементом.

## Формат комментария замены

```gherkin
# Элемент "<Исходное имя>" не найден. Использован похожий по смыслу элемент "<Фактическое имя>", подтвержденный через EDT-MCP.
```

## Формат комментария пропуска

```gherkin
# Реквизит "<Имя>" не найден в актуальной форме. Проверка пропущена, требуется актуализация тест-кейса.
```

# MCP Reference v5

## Vanessa AI MCP

Источник истины по:

- feature;
- Scenario;
- шагам Vanessa;
- примерам использования;
- стилю проекта.

Через существующие шаги Vanessa можно менять данные, если действие есть в тест-кейсе.

## EDT-MCP

Источник истины по:

- формам;
- элементам формы;
- командам;
- реквизитам;
- табличным частям;
- объектам конфигурации;
- типам и форматам реквизитов;
- возможности свободного ввода;
- похожим по смыслу элементам.

Если элемент не найден по точному имени, EDT Agent может искать похожий по смыслу элемент.

## ROCTUP/1c-mcp-toolkit

Источник тестовых данных из базы.

Разрешены:

- `get_metadata`;
- `execute_query`;
- `get_object_by_link`;
- `get_link_of_object`.

Запрещено:

- `execute_code`;
- изменение данных;
- write-операции.

## Главное правило

Изменение данных разрешено только через UI-действия, реализованные существующими шагами Vanessa Automation.
